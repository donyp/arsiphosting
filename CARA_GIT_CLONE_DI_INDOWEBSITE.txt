METODE 1: MENGGUNAKAN SSH (RECOMMENDED)
═══════════════════════════════════════════════════════════════════════════

STEP 1: Buka Terminal di Komputer Anda
───────────────────────────────────────────────────────────────────────────

Windows:
  ├─ Buka PowerShell
  │  (Start → Search "PowerShell" → Buka)
  │
  └─ Atau Command Prompt
     (Start → Search "cmd" → Buka)

Mac/Linux:
  └─ Buka Terminal


STEP 2: SSH ke Hosting Indowebsite
───────────────────────────────────────────────────────────────────────────

Command:
  ssh username@mail.arsipdig.com

Contoh lengkap:
  PS C:\Users\YourName> ssh arsipdig@mail.arsipdig.com

Ganti:
  - username = username hosting Anda (biasanya email atau kode customer)
  - mail.arsipdig.com = domain hosting Anda

Input Password:
  arsipdig@mail.arsipdig.com's password: [ketik password hosting]
  
Expected Output:
  Last login: Thu Sep 17 10:30:00 2026 from 192.168.1.1
  [arsipdig@hosting ~]$  ← Berhasil! Sekarang di server


STEP 3: Navigate ke Home Directory
───────────────────────────────────────────────────────────────────────────

Command:
  cd ~

Verify:
  pwd

Expected Output:
  /home/arsipdig


STEP 4: GIT CLONE REPOSITORY
───────────────────────────────────────────────────────────────────────────

Command:
  git clone https://github.com/donyp/arsiphosting.git

Expected Output:
  Cloning into 'arsiphosting'...
  remote: Enumerating objects: 4808, done.
  remote: Counting objects: 100% (4808/4808), done.
  remote: Compressing objects: 100% (XXX/XXX), done.
  Unpacking objects: 100% (4808/4808), done.
  
  ⏱️ Tunggu sampai selesai (5-15 menit tergantung kecepatan)


STEP 5: Navigate ke Folder Aplikasi
───────────────────────────────────────────────────────────────────────────

Command:
  cd arsiphosting

Verify:
  ls -la

STEP 7: VERIFY GIT STATUS
───────────────────────────────────────────────────────────────────────────

  Your branch is up to date with 'origin/master'.
  nothing to commit, working tree clean

METODE 2: MENGGUNAKAN FILE MANAGER (CPANEL)
═══════════════════════════════════════════════════════════════════════════

Jika SSH tidak available, gunakan cPanel File Manager:

STEP 1: Buka cPanel
───────────────────────────────────────────────────────────────────────────

1. Buka hosting control panel:
   URL: https://mail.arsipdig.com:2083 (atau sesuai domain Anda)
   
2. Login dengan username & password hosting


STEP 2: Upload Repository ke Hosting
───────────────────────────────────────────────────────────────────────────

Option A - Download sebagai ZIP, lalu upload:
  1. Buka: https://github.com/donyp/arsiphosting
  2. Klik: Code → Download ZIP
  3. Simpan file ZIP
  4. Buka cPanel File Manager
  5. Navigate ke: public_html/
  6. Upload file ZIP
  7. Extract file ZIP (klik kanan → Extract)
  8. Rename folder jika perlu

Option B - Git clone via cPanel Terminal (jika tersedia):
  1. Buka cPanel
  2. Cari: Terminal atau Command Line
  3. Jalankan: git clone https://github.com/donyp/arsiphosting.git
  4. Selesai!

❓ TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

MASALAH 1: "git: command not found"
─────────────────────────────────────────────────────────────────────────
Solusi:
  Git tidak terinstall di hosting
  
  Option 1: Contact support@indowebsite.com untuk install git
  Option 2: Gunakan cPanel Terminal untuk git clone
  Option 3: Download ZIP dari GitHub dan upload manual


MASALAH 2: "Permission denied (publickey,password)"
─────────────────────────────────────────────────────────────────────────
Solusi:
  Username atau password SSH salah
  
  ✓ Verifikasi username hosting
  ✓ Verifikasi password hosting
  ✓ Pastikan CAPS LOCK tidak aktif
  ✓ Cek email dari Indowebsite untuk credentials


MASALAH 3: "Connection timed out"
─────────────────────────────────────────────────────────────────────────
Solusi:
  Koneksi ke server gagal
  
  ✓ Periksa internet connection Anda
  ✓ Verifikasi domain/IP hosting benar
  ✓ Tunggu beberapa saat lalu coba lagi
  ✓ Contact Indowebsite support


MASALAH 4: "npm: command not found"
─────────────────────────────────────────────────────────────────────────
Solusi:
  Node.js tidak terinstall
  
  ✓ Contact support@indowebsite.com
  ✓ Atau gunakan cPanel Application Manager
  ✓ Atau verifikasi Node.js sudah terinstall: node -v


MASALAH 5: "fatal: repository not found"
─────────────────────────────────────────────────────────────────────────
Solusi:
  Repository URL salah atau tidak public
  
  ✓ Verifikasi URL: https://github.com/donyp/arsiphosting.git
  ✓ Pastikan repository adalah PUBLIC
  ✓ Cek typo di URL
