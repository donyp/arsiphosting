STEP 7: SETUP .ENV FILE
═══════════════════════════════════════════════════════════════════════════

1. Navigate ke: /public_html/arsiphosting/backend/

2. Lihat file: .env.example

3. Klik kanan pada .env.example → Copy

4. Klik kanan → Paste

5. Rename copy menjadi: .env

   (Atau gunakan Rename)

6. Klik kanan pada .env → Edit

7. Edit isi file dengan Supabase credentials:

   PORT=8080
   NODE_ENV=production
   SUPABASE_URL=https://your-project.supabase.co
   SUPABASE_SERVICE_ROLE_KEY=eyJhbGc...
   JWT_SECRET=your-secret-here
   SESSION_SECRET=your-session-secret
   ALLOWED_ORIGINS=https://arsipdigitalanka.my.id

8. Save file

═══════════════════════════════════════════════════════════════════════════
STEP 11: SETUP DOMAIN & REVERSE PROXY
═══════════════════════════════════════════════════════════════════════════

1. Buka cPanel

2. Klik: "Addon Domains" (di Domains section)

3. Add domain:
   - Domain: arsipdigitalanka.my.id
   - Document Root: /public_html/arsiphosting/

4. Setup .htaccess:
   - Buka File Manager
   - Navigate ke: /public_html/arsiphosting/
   - Create file: .htaccess
   - Isi dengan:

<IfModule mod_rewrite.c>
  RewriteEngine On
  RewriteCond %{REQUEST_FILENAME} !-f
  RewriteCond %{REQUEST_FILENAME} !-d
  RewriteRule ^(.*)$ http://localhost:8080/$1 [P,L]
</IfModule>

5. Save
